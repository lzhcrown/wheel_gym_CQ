一、成功率（SR）——记录通过结果和数量，之后离线计算
论文式(11)：S(i,j) = n_success(i,j) / N_agents，表示穿越地形单元的比例。
本文没有明确列出穿越终点条件、每格样本数或跨地形汇总方式。

框架已有 root_states 世界坐标、terrain_types/terrain_levels、reset_buf、
time_out_buf 和失败累计状态，但现有 done 不代表成功，存活到超时也不
必然代表成功。地形课程的升级条件也不能直接作为评估成功率。
建议每种固定地形、难度、起点设置清楚的目标线/目标区域：在时限内
到达目标且没有失败才算成功。分别记录 success、failure、timeout；
同一时间到达失败与超时边界时预先定义优先级，不丢弃失败试验。
只计算每次试验第一次终止的结果，自动reset后的新回合不能混入本次。
分别报告每格成功数/总次数以及各训练seed的结果，跨地形使用预先固定
的等权或样本权重。不要用8192个训练实例推断论文评估样本量。

二、平均机械功率与机械能量——可采集；电池电耗不能直接取得
论文第6页式(12)：
  P_net(k) = sum_j tau(k,j) * omega(k,j)              [W]
  E_net    = sum_k P_net(k) * dt_sim                 [J]
原式没有绝对值，也没有取正功；负功会抵消正功。它是带符号机械功，
不能未经说明改成绝对值功或电能。平均功率可据此定义 P_mean=E/T，
时间T必须与能量累计窗口一致。
论文表5列名 Power/J 的单位为焦耳，按单位应解读为能量而不是瓦特功率。
实机表7另报告 mechanical power proxy；第9页引用的 Appendix D 并不在
这份12页PDF中，无法核准其实机代理量的完整定义。

为避免正负功抵消，建议另外报告绝对机械功代理，并与论文原式分列：
  P_abs(k) = sum_j abs(tau(k,j) * omega(k,j))
  E_abs    = sum_k P_abs(k) * dt_sim
  P_abs_mean = E_abs / T
也可选正机械功 E_pos=sum_k sum_j max(tau*omega,0)*dt_sim；
E_net、E_abs、E_pos不能混用同一个名称，也不能把E_abs当作电池电耗。
真实电耗还需要电机效率、铜损、驱动/电子设备功耗或电流电压测量。

数据来源：env.torques 为实际传给仿真器的施加力矩，dof_state的速度分量为
真实关节角速度，覆盖12个腿关节和4个轮关节。动作向量是目标位置/速度，
不能用动作向量代替力矩。
采集位置：envs/nezha2/legged_robot.py 的 step() 物理子步循环，力矩
施加并仿真后刷新关节速度，逐子步保存实际力矩、前后角速度和dt；之后
可用子步前后角速度的平均值配合施加力矩离线积分。延迟开启时用self.torques，
不能用尚未实际施加的局部torques。
当前 sim.dt=0.005s（200Hz），decimation=4，策略周期0.02s（50Hz）。
只用策略步末的瞬时功率乘0.02s是粗近似，无法捕获中间子步的变化。
已有 _reward_joint_power 是策略步末的绝对机械功率惩罚，经奖励权重、
裁剪和汇总后不是原始功率/能量记录。

三、运输成本（COT）——可采集，必须统一质量、路程和能量定义
论文式(13)：COT_net = E_net / (M*g*d_total)，无量纲。
若采用上述绝对机械功代理，则明确命名 COT_abs = E_abs/(M*g*D)，
不将其称为论文原式的直接复现。

M必须是质量随机化之后的全机总质量，包括腿、轮、基座及负载。
框架的body_mass只存基座props[0].mass，不能作为全机质量。
应在创建机器人、应用刚体属性时保存sum(prop.mass for prop in body_props)。
g采用明确的重力加速度，固定评估场景下通常为9.81m/s^2。
论文未说明d_total采用水平路径、三维路径或净位移，需在本项目预先指定。
建议固定直线穿越任务报告沿目标方向的有效前进距离；涉及转弯时另列
水平轨迹长度，并保存原始世界位置以便核对。有效前进距离与路径长度
不能混用；绕圈/横向摆动不应被误解为完成了更多运输任务。
站立、原地旋转及几乎没有进展的回合，COT标记为不适用，记录原因，
同时保留其失败结果。不能靠任意小的分母或丢弃样本掩盖失败。
能量、时间、距离的统计窗口必须相同，不能在成功后继续累计其中一项。
建议成功穿越样本报告效率统计，同时报告失败数和失败样本的能量/进展，
避免仅看成功子集得出整体优劣结论。

四、速度不稳定率（VIR）——可采集，论文阈值缺失
第6页式(14)的含义是“加速度超过阈值的采样点占比”：
  a_i(k) = norm_2(v_i(k)-v_i(k-1)) / dt_sample
  VIR = sum_valid 1[a_i(k) >= a_threshold] / number_of_valid_samples
论文采用各试验相同长度的N*L作为分母。实际有提前失败时，应明确是
先算逐试验比例再平均，还是按有效采样点汇总；两者不能混同。
这不是速度误差、速度方差或速度标准差。匀速但速度跟错的策略可以有
很低的VIR，因此须与速度跟踪误差一起评估。

正文未给出阈值数值、速度的坐标系/维数、采样频率或滤波方式。
不能声称可以逐数复现论文VIR。建议：固定命令的稳态片段，用世界系
水平速度root_states[:,7:9]，统一50Hz采样，阈值单位m/s^2；也可以
研究三维速度，但应明确标记，爬坡/台阶中的竖直运动会改变结果。
若要采用低通滤波，所有组必须使用相同滤波器和窗口；先固定阈值和
采样方案再比较，可补充VIR随阈值变化的曲线。
启动、换向、命令跳变片段应另列瞬态测试，不与稳态混合。
不得跨环境reset对速度做差分，重置的状态跳变不是实际运动加速度。

五、速度跟踪误差——可直接采集并计算
建议主指标：平面速度向量RMSE，单位m/s：
  RMSE_xy = sqrt(mean_k[(vx(k)-cmd_vx(k))^2 + (vy(k)-cmd_vy(k))^2])
这里没有除以2，按平面误差向量长度定义；可另外分别报告RMSE_x、RMSE_y。
角速度单列，单位rad/s：
  RMSE_wz = sqrt(mean_k[(wz(k)-cmd_wz(k))^2])
也可增加MAE和95%误差分位数，反映典型误差与较大偏差。
线速度与角速度量纲不同，不直接相加；接近零命令时不使用除以目标
速度的百分比误差。若增加容差内比例，必须声明容差值和单位。

当前commands[:,0:2]为机体系vx/vy目标，commands[:,2]为角速度目标。
可与base_lin_vel[:,0:2]、base_ang_vel[:,2]匹配；heading_command=False。
倾斜地形上的机体系角速度z不严格等于世界航向角变化率；若需要航向
跟踪指标，应另定义，不能混叫同一个指标。
命令在step末callback可能重采样，因此step开始应克隆本次实际作用
的命令，重置前记录响应速度，避免把新命令与旧动作响应配对。
训练奖励使用指数映射和其他项混合，不能代替以物理单位计的跟踪误差。

六、建议的独立评估协议与后续采集位置
论文第5页说明20秒评估、恒定速度指令、400Hz控制频率；未给具体命令值。
本框架按现有200Hz物理/50Hz策略运行，不为模仿论文数值改动五组训练。
评估时限应根据区域大小与目标速度确定，不能把论文20秒直接套在长路线。
当前局部块入口默认整次尝试上限10秒，采用固定地形难度、随机入口位置、
固定姿态及恒定指令；旧region布局按路线长度估算时限。模型选择规则需统一。
测试地形使用独立seed，关闭地形/命令课程。先逐地形/难度/指令/训练
seed报告，再按固定权重汇总；并行环境不是独立的模型训练重复。
保留环境随机化的评估与固定参数评估应分开。原_compute_torques内
0.8～1.1随机缩放现已增加domain_rand.randomize_torque_scale开关；
训练默认保持原行为，独立评估明确关闭该开关。
